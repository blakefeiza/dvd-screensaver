# DVD Screensaver

A bouncing DVD logo at a steady pace. Every lap ends in a corner hit with confetti and a popup of total Superstore sales.
Click the logo to speed it up (1x, 1.4x, 1.9x, 2.6x, then back to 1x).

Plain web page, built for a Tableau Public Web Page object (Public cannot run extensions). The popup value is fixed.
